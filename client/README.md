# 🎨 Frontend SPA - Inventario TI

Esta es la capa de interfaz de usuario del sistema.

## 🚀 Inicio Rápido
Se recomienda utilizar el orquestador de la raíz:
```bash
cd ..
npm run setup
npm run dev:client
```

## 🛠️ Tecnologías
- **Vue 3** (Composition API)
- **PrimeVue 4** (UI Components)
- **Pinia** (State Management)
- **TailwindCSS** (Styling)
